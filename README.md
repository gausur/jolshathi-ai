🌧️ JolShathi AI

Climate Preparedness Assistant for Bangladesh

JolShathi AI is a simple web-based climate preparedness assistant designed to help people in Bangladesh think about rainfall and waterlogging risks and take practical precautions.

🌍 Problem

Heavy rainfall and urban waterlogging can disrupt daily life, commuting, and access to essential services. People need clear, accessible preparedness guidance.

💡 Our Solution

JolShathi AI provides easy-to-understand, rule-based guidance based on the rainfall level and waterlogging conditions selected by the user.

✨ Current Features

- Simple, mobile-friendly interface
- Bangla-language guidance
- User-selected rainfall levels
- Waterlogging condition input
- Practical preparedness suggestions
- Transparent, rule-based assessment

🛠️ Technology

- HTML
- CSS
- JavaScript
- GitHub Pages

🚀 Live Demo

https://gausur.github.io/jolshathi-ai/

📱 How to Use

1. Open the live demo.
2. Select the rainfall level.
3. Indicate whether waterlogging is present.
4. View the suggested precautions.

⚠️ Important Disclaimer

JolShathi AI currently provides an illustrative, rule-based assessment based on user inputs. It does not provide official weather forecasts, verified flood predictions, or professional emergency advice.
